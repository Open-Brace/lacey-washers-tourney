# Lacey Washers Tourney

Mobile-first washers tournament site for Lacey's graduation party.

## Features

- Randomized teams from the party roster
- Re-randomize teams until the draw looks right
- Optional manual seed editing, with automatic seed fill
- Interactive bracket with score entry
- Automatic winner advancement
- Live cross-device sync through Supabase realtime
- No authentication by design

## Local Development

```sh
npm install
npm run dev
```
